## 👋 About

I'm a **Distinguished Research Scientist at [Fastino Labs](https://www.fastino.ai)** (backed by Khosla Ventures and Microsoft Ventures), where I've trained multiple state-of-the-art frontier models. Before that I studied **theoretical physics at the University of Cambridge**.

- 🔐 **Building** formal verification and verified recursive self-improvement (RSI) for AI agents
- ⭐ **3,200+ GitHub stars** as sole author on projects in RSI, formal verification and SOTA agents
- 🌐 **More at** [sahibzada-allahyar.github.io](https://sahibzada-allahyar.github.io)

### 🔐 [Formal-Verification-RSI](https://github.com/sahibzada-allahyar/Formal-Verification-RSI) &nbsp;<img src="https://img.shields.io/github/stars/sahibzada-allahyar/Formal-Verification-RSI?style=flat-square&color=f59e0b&logo=github" align="center"/>

### 🧠 GLiDE: Fastino's frontier decision model
Fastino GLiDE v1.2 ranked first overall on Hugging Face's [Jev Decision Index](https://huggingface.co/spaces/multimodalart/jev-decision-index), ahead of OpenAI's Decision API, Microsoft's decision model, Baseten's Mammoth-1, Perplexity's Decider and Cloudflare's Clef.

- 📝 [Introducing GLiDE: The First Thinking Decision Model](https://fastino.ai/blog/introducing-glide-the-first-thinking-decision-model)
